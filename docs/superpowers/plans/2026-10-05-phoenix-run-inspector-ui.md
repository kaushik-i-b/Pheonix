# PHOENIX Run Inspector UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@phoenix/web`, a read-only Next.js run inspector over the persisted PHOENIX artifacts whose centerpiece is an evidence & citations viewer that re-checks every recorded quote against the real `examples/legacy-bank` bytes, and ship it as a prebuilt static export to a Vercel preview URL.

**Architecture:** A static-export Next.js App Router package (`apps/web`). A build-time data layer (`apps/web/src/data/*`) reads `artifacts/` and `examples/legacy-bank/` from disk with tolerant zod projections, strict display-whitelisting and path/secret sanitization. Server components render every page; exactly two small client components add interactivity (timeline filter). Vercel receives only the prebuilt static output, after a secret-scan gate.

**Tech Stack:** Next.js 16.3.8 (App Router, `output: 'export'`), React 19.3.0, Tailwind CSS 4.3.3 + `@tailwindcss/postcss`, zod ^3.24.1 (v3 — NOT v4; repo-aligned), TypeScript ^5.7.2 strict, vitest ^2.1.8, pnpm workspace.

**Spec:** `docs/superpowers/specs/2026-10-05-phoenix-run-inspector-ui-design.md` — read it first. Every task below argues from that spec; the spec wins on any conflict.

## Global Constraints

- **Read-only.** Never write to a run, never launch or resume pipeline stages, never mutate artifacts. The only computed value is the UI byte re-check, always labeled "UI-computed" and never merged with pipeline-recorded results.
- **Never render:** `agent/transcript-*.json`, `agent/tool-log-*.json`, `run/prompt-*.txt`, `llm.completed` raw body, `tool.invoked.outputSummary` (contains raw file bytes), differential comparison `legacy`/`modern` bodies (render only `scenarioTitle`, `category`, `outcome`, `equal`, `durationMs`, `normalizationApplied`).
- **Sanitize every displayed string** through `sanitizeForDisplay`: repo-absolute paths become repo-relative; other machine-absolute paths become `[host path withheld]`; `sk-…`, `AQ.…`, `Bearer …`, `Authorization: …` are masked.
- **Byte comparison is exact** — only line-ending style (CRLF→LF) is normalized; a matching prefix is not a match.
- **Timeline preserves file append order.** `seq` restarts per writer process; never re-sort by `seq`. Order in file = chronological (`at` is monotonic across the file).
- **Every iteration renders; failures are never collapsed.** Zero counts render as "0 recorded (this is what the artifact says)".
- **No `any`** (eslint error). Tolerant zod projections; every displayed field validated. Zod is v3 (`^3.24.1`), matching `apps/cli`.
- **Root `pnpm verify` stays green** (typecheck + lint + test across packages; web participates).
- **Never commit** `artifacts/`, `.env`, or `.vercel`. Deploy is prebuilt-only; preview URL by default; never fabricate a link.
- Tests use temporary fixture trees only — never the real (gitignored) `artifacts/` directory. Only the build smoke (Task 18) and browser check (Task 19) read real data.

**Design language (locked; derives from the spec's trust story):** "instrument deck + exhibit sheets". Dark instrument chrome (`#10151C` base, `#1A212B` raised, `#2A3340` lines, `#E7ECF2` text, `#8C97A5` mist) frames cool off-white paper exhibit sheets (`#F6F7F5` paper, `#1B2430` ink, `#5A6572` soft ink) that carry the evidence. Brass `#E8A33D` is the signal accent (active nav, focus, UI-computed markers). Signature element = the exhibit sheet: a source excerpt with line-number gutter, brass left rail, and a re-check stamp chip. 3px radii, stamp-style chips, motion limited to a rail sweep honoring `prefers-reduced-motion`.

### Task 2: `repo-root.ts` + `sanitize.ts` — workspace resolution and display safety

**Files:** Create `apps/web/src/data/repo-root.ts`, `apps/web/src/data/sanitize.ts`; Test `apps/web/test/data/repo-root.test.ts`, `apps/web/test/data/sanitize.test.ts`

**Interfaces:**
```ts
export interface Workspace {
  repoRoot: string;
  artifactsDir: string;
  legacyRoot: string;
  buildTime: string | null;               // ISO string when snapshot mode
  sourceMode: "working-tree" | "snapshot";
}
export function findRepoRoot(startDir: string): string;   // walk up for pnpm-workspace.yaml; throw Error("repo root not found above <dir>") otherwise
export function resolveWorkspace(opts?: { cwd?: string; env?: Record<string, string | undefined>; now?: Date }): Workspace;
export function displayPath(ws: Workspace, p: string): string;

export function maskHostPaths(text: string): string;
export function maskSecrets(text: string): string;
export function sanitizeForDisplay(text: string, ws: Workspace, maxLength?: number): string; // default 240
```

**Behavior (exact):**
- `resolveWorkspace`: `repoRoot = findRepoRoot(opts.cwd ?? process.cwd())`; `artifactsDir = env.PHOENIX_ARTIFACTS_DIR || repoRoot + '/artifacts'`; `legacyRoot = env.PHOENIX_LEGACY_ROOT || repoRoot + '/examples/legacy-bank'`; empty-string env counts as unset. `buildTime = env.PHOENIX_BUILD_TIME` if non-empty, else if `env.NODE_ENV === "production"` then `(opts.now ?? new Date()).toISOString()`, else `null`. `sourceMode = buildTime ? "snapshot" : "working-tree"`.
- `displayPath`: starts with `repoRoot + path.sep` → the relative remainder; `path.isAbsolute(p)` → `"[host path withheld]"`; else `p` unchanged.
- `maskHostPaths` regex (repo-absolute handled before this runs): `/(?<![\w.-])\/(?:Users|home|private|var|tmp|opt|Volumes)\/[^\s"'`)\]},;]*/g` → `"[host path withheld]"`.
- `maskSecrets`: `\bsk-[A-Za-z0-9_-]{8,}` and `\bAQ\.[A-Za-z0-9_.-]{8,}` → `[redacted api key]`; `\bBearer\s+[A-Za-z0-9._~+/=-]{8,}` (case-insensitive) → `Bearer [redacted]`; `\bAuthorization\s*[:=]\s*[^\s"'`]{8,}` (case-insensitive) → `Authorization: [redacted]`.
- `sanitizeForDisplay` order: (1) `text.split(ws.repoRoot + path.sep).join("")`; (2) `maskHostPaths`; (3) `maskSecrets`; (4) collapse whitespace runs to single spaces and trim; (5) clip to `maxLength` with `…` when longer.

**Tests (written first, exact cases):**
- `findRepoRoot`: fixture workspace root found from a nested dir; throws when no marker up the chain.
- `resolveWorkspace`: defaults use fixture repo root; env overrides win; empty string env ignored; `NODE_ENV=production` without `PHOENIX_BUILD_TIME` → snapshot with injected `now`; `PHOENIX_BUILD_TIME` set → snapshot with that exact value; dev env → working-tree, `buildTime` null.
- `displayPath`: under-root → `examples/legacy-bank/src/Main.java`; other absolute → `[host path withheld]`; relative untouched.
- `sanitizeForDisplay`: a `tool.denied`-style reason carrying the fixture repo absolute path renders repo-relative; a `/Users/nobody/secret/x` string renders `[host path withheld]`; `sk-474dabcdefghijk` → `[redacted api key]`; `"Authorization: Bearer abcdefgh12345"` loses the value; 1000-char string clipped to 240 with `…`; surrounding whitespace collapsed.
- Negative: `"Authorization"` alone and `"bearer of news"` are not masked (bounds required).

### Task 12: `recheck.ts` — the five-state byte re-check (UI-computed)

**Files:** Create `apps/web/src/data/recheck.ts`; Test `apps/web/test/data/recheck.test.ts`

**Interfaces & exact algorithm:**
```ts
export type RecheckResult =
  | { state: "matched" }
  | { state: "drifted"; firstDiffLine: number | null }
  | { state: "relocated"; foundStart: number; foundEnd: number }
  | { state: "file-missing" }
  | { state: "out-of-range"; lineCount: number };
export function recheckEvidence(ws: Workspace, location: { path: string; startLine: number; endLine?: number }, quote: string): RecheckResult;
```
1. `src = readLegacySource`; `!src.ok` → `file-missing`.
2. `lines = splitLines(src.content)`; `start = location.startLine`; `end = location.endLine ?? start`.
3. `start < 1 || end < start || end > lines.length` → `out-of-range` with `lineCount = lines.length`.
4. `recorded = quote.replace(/\r\n/g, "\n").replace(/\r/g, "\n")` (only normalization allowed); `actual = lines.slice(start - 1, end).join("\n")`.
5. `actual === recorded` → `matched`.
6. Else search `recorded` inside `splitLines(...).join("\n")`-style normalized full text; if found, compute `foundStart`/`foundEnd` line numbers; if that range differs from `start..end` → `relocated`.
7. Else `drifted` with `firstDiffLine` = first line index in `start..end` whose content differs (or `end + 1`-style boundary when lengths differ); `null` when recordable boundary only.

**Tests (all five states + traps):** matched exact; trailing-whitespace difference → drifted; quote shorter than range → drifted; prefix-only match (quote is a prefix of the range text but not equal) → drifted, never matched; CRLF file vs LF quote → matched; quote moved one line down → relocated with exact found range; missing file → file-missing; `endLine` beyond EOF → out-of-range with lineCount; traversal path → file-missing; `endLine` omitted defaults to `startLine`.

**Steps:** red → green → `typecheck` → commit `"Add five-state evidence byte re-check."`
